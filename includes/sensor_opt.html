Sensor Optimization

Optimization algorithm for sensor placement in piston thermal testing

Motivation

Improve FE modeling capabilities for pistons

To achieve

  • Greater predictive accuracy
  • Reduced uncertainty in model

Motivation

Improve FE modeling capabilities for pistons

The goal is to develop a framework for identifying optimal measurement locations

  • Better experimental data improves calibration capabilites

Approach

2D Piston Model

Mesh

  • 2D slice of 3D piston CAD
  • 1st order solid diffusive elements: trias and quads
    • 0.7 mm element size at crown
    • 2.5 mm element size at skirt

Piston Model Unknown BCs

The proposed approach is two-phase and based on one-at-a-time optimization where each sensor is optimized to estimate a single unknown parameter
The unknown BCs are grouped to match the number of available sensors (8)

Approach

The two-phase one-at-a-time approach holds unknowns at fixed values for computational efficiency so many configurations of potential truth are considered

Potential Truth

  • Generate a 25x8 Latin hypercube design
  • 25 configurations of the 8 $\theta$, denote this as $\boldsymbol{\Theta}^* = (\boldsymbol{\theta}^*_1,\boldsymbol{\theta}^*_2,\ldots,\boldsymbol{\theta}^*_{25})$
  • Consider each of these 25 configurations a different possibility of the "true" values of the unknown BCs

Approach

First stage optimization

  • Genetic algorithm (GA) optimization for each sensor at each $\boldsymbol{\theta}^*_i$
    • Genetic algorithm efficiently explores the space
    • Unique set of results for each $\boldsymbol{\theta}^*_i$

Approach

Location Mapping

Each candidate solution in the GA is defined in $\mathbb{R}^2$
  • Must be mapped to the piston geometry to explore only feasible locations
  • We already have a set of discrete points approximating the piston geometry (the FE mesh)
    • Map all candidate solutions to the FE node coordinate with the least Euclidean distance

Approach

Data Synthesis

Data synthesis

For a given configuration $\boldsymbol{\theta}^*_i$
  1. Solve the FE model
  2. Draw 200 samples of Gaussian noise and add this to the FE model results

Approach

Objective Function

Fisher Information

$$O = \frac{-\partial^2 \log L}{{\partial \theta}^2}$$
  • Negative curvature of the log likelihood with respect to a given $\theta$ at the MLE
  • A measurement of how sensitive the likelihood is to this $\theta$

Approach

Candidate Optima

Genetic Algorithm Results

For each setting of $\boldsymbol{\theta}^*_i$, the GA results are a population of candidate optima
  • Each population is a collection of multiple candidates for maximum Fisher information
  • Each is dependent on the specific $\boldsymbol{\theta}^*_i$ used to generate data for that case

Approach

Phase 2 Optimization

  • Calculate the boundary around all of the candidate solution populations via $R=[x_{\textrm{min}},x_{\textrm{max}}] \times [y_{\textrm{min}},y_{\textrm{max}}]$
  • Map this to the FE mesh to find all nodes inside the boundary, $R'$
  • For each location in $R'$, we find the minimum Fisher information, minimized over the different configurations of $\boldsymbol{\Theta}^*$, denoted as $\mathcal{I}_{\textrm{min}}$
  • We find the location that has the greatest $\mathcal{I}_{\textrm{min}}$
  • This location is the "safest" choice for placing a sensor

Validation Approach

Comparison Metrics

Comparison Metrics

Two comparison methods

  • Box plots showing distribution of metrics for the the two data sets

Conclusions

Posterior variance

  • Reduced posterior variance when calibrating to the algorithm-selected locations in 99% of parameter configurations
  • Average reduction in posterior variance of 70.4%
    • Average standard deviation decrease in estimates of unknown boundary conditions \[76 \space Wm^{-2}K^{-1}\]

Conclusions

Posterior Error

  • Reduced MSE when calibrating to the algorithm-selected locations in 83.5% of parameter configurations
  • Average reduction in MSE of 43.9%
    • Average RMSE decrease in estimates of unknown boundary conditions \[136 \space Wm^{-2}K^{-1}\]
