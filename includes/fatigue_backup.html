Approach

Data Representation

  • $N$ cycles to failure for each test: $\mathbf{N} = (N_1,N_2,\ldots,N_m)$
  • Corresponding function of stress over cycles: $\mathbf{s}(n) = (s_1(n),s_2(n),\ldots,s_m(n))$

Approach

Cycles Partition

Create a grid of cycles, $\boldsymbol{\tau}$ containing
  • All $\mathbf{N}$
  • Any cycle $n$ where stress changes

Posterior Sampling

  • Bayes' theorem: $$\footnotesize \begin{align*} \pi(\boldsymbol{\gamma},\boldsymbol{\beta}| \mathbf{N},\mathbf{s}(n)) \propto \\ \pi(\mathbf{N}| \mathbf{s}(n),\boldsymbol{\gamma},\boldsymbol{\beta}) \times \\ \pi(\boldsymbol{\gamma}) \pi(\boldsymbol{\beta}) \end{align*}$$
  • Metropolis-Hastings to sample the spline coefficients: $\boldsymbol{\beta}$ and $\boldsymbol{\gamma}$

Optimal Experiment Design

  1. At the current state, $m$, there are $m$ previous observations
  2. Estimate the posterior distributions: $\pi(\boldsymbol{\gamma},\boldsymbol{\beta}|\mathbf{N}^m,\mathbf{s}(n))$
  3. Optimize next design point, $\mathbf{d} \in \mathcal{D}$ with objective function $O(\mathbf{d})$, conditioned on the posterior
  4. Test at new design point $\mathbf{d}$
  5. Set state to $m+1$, append new data, and repeat

Objective Function

We can construct our objective function based on entropy to select the design point $\mathbf{d}$ that maximizes the reduction in entropy for the next test point

Data Synthesis

  • Given: $\mathbf{d} = (s_0, \Delta s, n_0)$
  • Sample specimen strength factor: $R \sim 10^{\textrm{N}(0,0.1)}$
  • Iteratively evaluate damage for each cycle count and stress level until $D=1$

$S$-$N$ and Damage Models

  • The $S$-$N$ model determines the number of cycles to failure at a given stress level, for constant load amplitude testing
  • The cumulative damage model determines how load sequence of variable load amplitude affect the cycles to failure for a specimen

$S$-$N$ Models

  • MMPDS-05 regression curve
  • log-bilinear model
  • Basquin's equation

All modeled to represent the $S$-$N$ curve of AISI 4340 steel at room temperature

Cumulative Damage Models

  • Palmgren-Miner
  • Kwofie-Rhabar
  • Manson-Halford
  • Modified Aeran

Palmgren-Miner

$$D = \sum d_i = \sum \frac{n_i}{N_i}$$
  • First proposed damage model
  • Common due to its simplicity
  • Inaccurate, does not consider effects of loading sequence

Kwofie-Rhabar

$$D = \sum_i d_i = \sum_i \frac{n_i}{N_i} \frac{\ln N_i}{\ln N_1}$$
  • Modification of Palmgren-Miner
  • Adds an interaction coefficient to account for loading sequence

Manson-Halford

$$\footnotesize \begin{align*} D = \bigg[ \left[ \left[ \left(\frac{n_1}{N_1} \right)^{\alpha_{1,2}} + \frac{n_2}{N_2}\right]^{\alpha_{2,3}} + \frac{n_3}{N_3} \right]^{\alpha_{3,4}} \\ + \cdots + \frac{n_{i-1}}{N_{i-1}} \bigg]^{\alpha_{i-1,i}} + \frac{n_i}{N_i} \end{align*}$$
where $\alpha_{i-1,i} = \left(\frac{N_{i-1}}{N_i}\right)^{0.4}$

Manson-Halford

  • Further improvement on the Palmgren-Miner model
  • Recursive interaction affects, better accounting for load sequence
  • Truly non-linear damage model

Modified Aeran

$$D_{i+1} = \left|1 - \left[1 - \frac{n_{(i+1),total}}{N_{i+1}} \right]^{\delta_{i+1}} \right|$$
where $\delta_i = \frac{-1.25}{\ln N_i}$

Modified Aeran

and $n_{(i+1),total} = n_{(i+1),eff} + n_{(i+1)}$ with $n_{(i+1),eff} = N_{i+1} \left[1 - \left(1 - D_i \right)^{\frac{\mu_{i+1}}{\delta_{i+1}}} \right]$ and $\mu_{i+1} = \left(\frac{s_i}{s_{i+1}} \right)^2$

Modified Aeran

  • Also a truly non-linear damage model
  • Dual-exponential form with $\delta_{i+1}$ and $\mu_{i+1}$ to account for loading sequence
